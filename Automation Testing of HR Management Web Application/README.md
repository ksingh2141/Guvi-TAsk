# OrangeHRM Automation Framework

## Project

Automation Testing of OrangeHRM using Selenium, Python, Pytest and Page Object Model.

---

## Tech Stack

- Python
- Selenium
- Pytest
- Page Object Model
- OpenPyXL
- pytest-html
- WebDriver Manager

---

## Features

- Data Driven Login
- Positive & Negative Testing
- Cross Browser Execution
- HTML Reports
- Explicit Waits
- Logging
- Exception Handling
- Reusable Page Objects
- Screenshot Support
- User Creation
- User Search
- Forgot Password
- Assign Leave
- Claim Creation
- My Info Validation

---

## Execute

pytest

pytest --browser chrome
